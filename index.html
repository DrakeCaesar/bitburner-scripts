Bitburner scripts - HTML tools

Local tools that run against the game's own models and strategies.

Interactive

Stock trader benchmark
Seeded model of the in-game stock market driving the real strategy from src/libraries/stock/trader.ts. Multi-seed stats, buy-and-hold baseline, config grid sweep.
build: pnpm run stock:viz | self-contained, opens straight from disk
KingOfTheHill altitude profiles
Altitude curves and per-difficulty solve counts for the dnet KingOfTheHill solver, run in browser workers.
build: pnpm run test:koth:bundle | needs to be served over http (module worker)
IPvGO engine bench
Bench and tuning UI for the native IPvGO engine: run games, stream progress, inspect moves.
run: pnpm run server then open http://localhost:3010/bench (set IPVGO_PORT to change the port) | needs the native engine built

Serving this page

This file is the landing page for the repo root, so any static server rooted here shows it at /. KingOfTheHill needs a real http origin, so use pnpm run tools and open http://localhost:8123/. The stock benchmark works either way - double-clicking it is fine.

CLI equivalents

  • pnpm run test:stock - stock benchmark, same model without the page
  • pnpm run test:stock -- --selftest - verify the market model against the game's formulas
  • pnpm run test:koth - KingOfTheHill solver simulation
  • pnpm run test:koth:bench - KingOfTheHill benchmark across all difficulties
