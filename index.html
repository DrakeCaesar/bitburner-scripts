Bitburner scripts - HTML tools

Local tools that run against the game's own models and strategies.

Interactive

Stock trader benchmark
Seeded model of the in-game stock market driving the real strategy from src/libraries/stock/trader.ts. Seeds run in parallel workers; multi-seed stats, buy-and-hold baselines, genetic tuning, config grid sweep. Settings persist in localStorage.
run: pnpm run tools | up to 12 parallel workers
KingOfTheHill altitude profiles
Altitude curves and per-difficulty solve counts for the dnet KingOfTheHill solver, run in browser workers.
run: pnpm run tools | solver edits reload the page
IPvGO engine bench
Bench and tuning UI for the native IPvGO engine: run games, stream progress, inspect moves.
run: pnpm run tools then open /bench | starts the engine server too (set IPVGO_PORT to change its port) | needs the native engine built

Serving this page

pnpm run tools serves every page from http://localhost:5173/ (HTML_TOOLS_PORT overrides) and reloads whichever one you edit, together with the model sources it imports. It also starts the IPvGO engine server that the bench page needs, proxied as /api, so one command is enough for all of them. Pages import their TypeScript sources directly - there is no per-tool build step. All these pages share the look and controls in webui/toolUi.css.

CLI equivalents

  • pnpm run test:stock - stock benchmark, same model without the page
  • pnpm run test:stock -- --selftest - verify the market model against the game's formulas
  • pnpm run test:koth - KingOfTheHill solver simulation
  • pnpm run test:koth:bench - KingOfTheHill benchmark across all difficulties
